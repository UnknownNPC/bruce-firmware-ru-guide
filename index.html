Меню Bruce: что делает каждый инструмент

Прошивка Bruce превращает ESP32-устройство (M5Stick, Cardputer, Lilygo T-Embed и др.) в мультитул для работы с радио, RFID/NFC, ИК и сетями. Ниже — все пункты меню по категориям: коротко что делает и практическое применение с конкретными брелоками, картами и устройствами.

Только для законного использования: тестируйте на своих устройствах или с письменного разрешения владельца. Атаки на чужое оборудование и сети незаконны.

01

RF

Sub-GHz · 300–928 МГц · CC1101
Scan/copy

Ловит сигнал пульта и сразу копирует его для повторной отправки.

ПрактикаКлонирование брелоков ворот и шлагбаумов со статическим кодом: старые Came TOP-432NA, Nice Flo, Doorhan, BFT. Не работает с «прыгающим» кодом KeeLoq.
Record RAW

Запись «сырого» сигнала целиком, без разбора протокола.

ПрактикаСохранение нестандартных сигналов: беспроводные звонки, датчики TPMS в шинах, метеостанции, дешёвые радиорозетки.
Custom SubGhz

Ручная отправка своего сигнала: частота, протокол и данные вручную.

ПрактикаОтправка кода на 433.92 / 315 / 868 МГц — например повтор ранее записанной команды радиорозетки.
Spectrum

Простой анализатор спектра — показывает активность на частоте.

ПрактикаПроверить, на какой частоте (433 или 868 МГц) работает пульт, прежде чем копировать.
RSSI Spectrum

Спектр с индикацией уровня сигнала (RSSI) для модуля CC1101.

ПрактикаПоиск источника помех или направления на работающий передатчик по силе сигнала.
SquareWave Spec

Показ сигнала в виде прямоугольной волны для анализа тайминга.

ПрактикаОпределить длину импульсов неизвестного протокола, чтобы декодировать кастомный пульт.
Spectogram

Водопадная диаграмма (waterfall) — частоты во времени.

ПрактикаНаглядно поймать кратковременные всплески от брелока в шумном эфире.
Listen

Прослушивание эфира через динамик (демодуляция в звук).

ПрактикаАудиоконтроль активности на частоте — слышно, когда кто-то нажимает пульт рядом.
Bruteforce атака

Перебор кодов (де Брёйн) для устройств с фиксированным кодом.

ПрактикаОткрытие старых ворот с DIP-переключателями и 8–12-битным кодом (ранние Came, Nice, Genie). Против rolling-code бесполезно.
Jammer атака

Глушилка — забивает выбранную частоту помехами.

ПрактикаТест устойчивости своей 433/868 МГц сигнализации к подавлению (в лаборатории, не в эфире общего пользования).
Config

Настройка пинов TX/RX, выбор модуля CC1101 и рабочей частоты.

ПрактикаПереключение между встроенным передатчиком и внешним CC1101 для большей дальности.
Команды
RF TX Pinпин передатчика
RF RX Pinпин приёмника
RF Moduleвстроенный или CC1101
RF Frequencyчастота по умолчанию (433/315/868)

RFID / NFC

Read tag

Считывает UID и данные NFC-метки (TagOMatic) для копирования.

ПрактикаЧтение Mifare Classic 1K: офисные пропуска, карты домофона, ключи гостиниц, транспортные карты.
Read EMV

Читает открытые данные с чипа банковской карты.

ПрактикаС Visa / Mastercard PayWave/PayPass считываются номер карты (PAN) и срок действия — демонстрация рисков бесконтакта.
Read 125kHz

Чтение низкочастотных меток 125 кГц.

ПрактикаСиние круглые брелоки-«таблетки» домофонов EM4100 / TK4100, а также карты HID Prox, Indala.
Scan tags

Режим последовательного сканирования нескольких меток.

ПрактикаБыстро проверить связку пропусков и брелоков, не заходя в чтение по одной.
Load file

Загрузка сохранённого дампа карты с SD для записи/эмуляции.

ПрактикаВосстановить свой домофонный ключ из ранее сохранённого .nfc файла.
Erase data запись

Стирание/сброс перезаписываемой метки.

ПрактикаОчистка «магических» карт UID-changeable перед записью нового дампа.
SRIX Tool

Работа с чипами SRIX/SRI (только с PN532 в I2C).

ПрактикаМетки SRI512 / SRIX4K — билеты и метки на складах/в музеях.
Emulate / Write NDEF

Эмуляция и запись NDEF-сообщений на метку.

ПрактикаЗаписать ссылку, Wi-Fi или визитку на чистый стикер NTAG213/215.
Amiibolink

Эмуляция игровых NFC-фигурок.

ПрактикаПодмена Amiibo для Nintendo Switch (Zelda, Smash) без покупки самих фигурок.
Chameleon

Управление устройствами-эмуляторами карт через Bruce.

ПрактикаХранение и переключение нескольких Mifare-карт в ChameleonUltra как одной «универсальной» картой.
PN532 BLE / UART

Подключение внешнего NFC-модуля PN532 по BLE или UART.

ПрактикаИспользование PN532Killer для эмуляции и атак на карты через беспроводную связь.
Config

Выбор RFID-модуля и добавление ключей Mifare.

ПрактикаДобавить известные ключи Mifare (A0A1.., FFFF..) для чтения защищённых секторов.
Команды
RFID Moduleвыбор модуля: PN532, RC522, ST25R3916, M5 RFID2
Add MIF Keyдобавить ключ Mifare в словарь для брутфорса секторов

ПрактикаУвеличить повторы для капризных приёмников, ловящих сигнал не с первого раза.

ПрактикаЗаставить автомагнитолы с RDS-TA переключиться на вашу трансляцию как «дорожную сводку».
