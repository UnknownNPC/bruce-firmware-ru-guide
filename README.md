# Bruce Firmware — русский справочник меню

Наглядный справочник по всем пунктам меню прошивки [**Bruce**](https://github.com/BruceDevices/firmware) для устройств на ESP32 (M5StickC, Cardputer, Lilygo T-Embed и др.). Для каждой функции — краткое описание, вложенные под-команды и **практическое применение** с конкретными брелоками, картами и устройствами.

## 🔗 Открыть справочник

**https://unknownnpc.github.io/bruce-firmware-ru-guide/**

Одностраничный сайт, светлая и тёмная темы, оглавление по категориям.

## Что внутри

- **16 категорий:** RF (Sub-GHz), RFID/NFC, IR, FM, LoRa, WiFi, BLE, NRF24, Ethernet, GPS, Others, Files, Connect, Scripts, Clock, Config.
- Для пунктов-контейнеров (WiFi Atks, BLE Spam, BLE Suite, BadUSB & HID и др.) раскрыты **реальные под-команды** из исходников — без «и т.д.».
- Строка **«Практика»** у каждого инструмента: где применяется и с какими устройствами (например Came TOP-432NA, EM4100, Mifare Classic, DS1990, Logitech Unifying, AirPods/Apple TV).
- Опасные/наступательные функции помечены отдельно.

## Версия

Соответствует прошивке Bruce **v1.16.1** (проверено: состав меню идентичен ветке `main`). Источник — репозиторий [BruceDevices/firmware](https://github.com/BruceDevices/firmware). Набор пунктов зависит от модели устройства, сборки (LITE/full) и подключённых модулей (CC1101, PN532, nRF24, W5500, GPS).

## Дисклеймер

Материал носит справочно-образовательный характер. Используйте инструменты только на собственном оборудовании или с письменного разрешения владельца. Атаки на чужие устройства и сети незаконны.
